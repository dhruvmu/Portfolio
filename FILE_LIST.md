## 🚀 How to Copy Everything

### Method 1: Download Individual Files
1. Copy each file content from this project
2. Create the same folder structure in your computer
3. Paste the content into each file

### Method 2: Copy Project Structure
1. Create main folder: `portfolio-project`
2. Inside it, create these folders:
   - `client/`
   - `client/src/`
   - `client/src/components/`
   - `client/src/components/ui/`
   - `client/src/hooks/`
   - `client/src/lib/`
   - `client/src/pages/`
   - `server/`
   - `shared/`

### Method 3: Use Git (If Available)
```bash
git clone [repository-url]
cd portfolio-project
npm install
npm run dev
```
